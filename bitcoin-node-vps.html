Bitcoin Node on a Cheap VPS (2026)

Full node, pruned node, Lightning — what a $5–10 box can actually do.

Bottom line: a pruned Bitcoin full node runs comfortably on a 2 vCPU / 4 GB VPS with ~10 GB disk, and a Lightning node on top is feasible. A full unpruned node (600+ GB) is out of budget-VPS reach on storage, but pruned is the smart default for most hobby setups anyway.

Reality check: a VPS Bitcoin node is centralized-ish — you're renting someone else's hardware. For self-sovereignty that matters, run your own iron. For privacy, API access, and routing your own Lightning channels, a VPS is fine.
