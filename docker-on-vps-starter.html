Install Docker

On Debian/Ubuntu, the official convenience script works and is the most-maintained path:

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker
docker --version

Then verify Compose v2 is included: docker compose version.
