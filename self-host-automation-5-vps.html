Self-Hosting Automation Tools on a $5 VPS

You don't need a big cloud bill to run your own automation stack. Here's how to run n8n (workflow automation), Uptime Kuma (monitoring), and a couple of side tools on a single cheap VPS.

Why self-host instead of free tiers

Free SaaS tiers come with limits and, often, data residency you don't control. A $5 VPS gives you full control, no per-run costs, and the tools you already know. For anyone automating real workflows, the independence beats the sticker price of a free plan.

The stack

n8n          -> workflow automation
Uptime Kuma  -> uptime monitoring + status page
Caddy        -> automatic HTTPS reverse proxy
Docker       -> runs everything

Quickstart (Docker Compose)

services:
  n8n:
    image: n8nio/n8n
    ports: ["127.0.0.1:5678:5678"]
    volumes: ["./n8n:/home/node/.n8n"]
    restart: unless-stopped
  uptime-kuma:
    image: louislam/uptime-kuma
    ports: ["127.0.0.1:3001:3001"]
    volumes: ["./kuma:/app/data"]
    restart: unless-stopped

Expose both through Caddy for HTTPS instead of binding them to the internet directly.

Don't skip the backup

Your automation is data. Back up the ./n8n and ./kuma folders daily — rsync to another box or an object store. Restore from snapshot is your recovery plan. A $5 VPS with a cron backup is more resilient than most free-tier setups.

Security for a personal box

  • Disable root password login; use SSH keys.
  • Firewall to only 22/80/443.
  • Put reverse proxy in front of tools (never expose the app port).
  • Daily unattended-upgrades for patches.
